# S302-patterns-php

**Description**: 
Exercises focused on the Singleton pattern and dependency injection. Through these exercises, I learned how both concepts work and practiced applying them in PHP.

## Technologies

* PHP

## Installation and Execution

1. Clone the repository:

```bash
git clone (https://github.com/imjrbarreto/s302-patterns-php)
```

2. Navigate to the project folder:

```bash
cd s302-patterns-php/01-level
```

  1. To navigate the *Singleton* activity:
```bash
cd singleton
```

  2. To navigate the *Dependency Injection* activity:
```bash
cd dependency-injection
```

3. Start the PHP built-in terminal:
 
```bash
php index.php
```
